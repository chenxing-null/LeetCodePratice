[相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/?envType=study-plan-v2&envId=top-100-liked)

给你两个单链表的头节点`headA`和`headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回`null`。

- 设第一条链表的长度为 $x + z$，第二条链表的长度为$y+z$，其中$z$是两条链表的公共部分的长度。
- 例如第一条链表为$a_1\rightarrow a_2\rightarrow c_1\rightarrow c_2\rightarrow c_3\rightarrow null$，第二条链表为$b_1\rightarrow b_2\rightarrow b_3\rightarrow c_1\rightarrow c_2\rightarrow c_3\rightarrow null$。则$x=2,y=3,z=4$，但不论$x,y,z$的取值如何，永远都有$(x+z)+y=(y+z)+x$存在。
- 根据这个等式我们可以明白，令`p`和`q`两个指针分别从$a_1$和$b_1$出发，每次两者的步长都一样，当`p`走到$null$后，我们让其跳到$b_1$，当`q`走到$null$后，我们让其跳到$a_1$处。那么当两者都走了$x+y+z$步长后两个指针一定指向同一地址。
- 例如，当两条链表没有交点时，$a_1\rightarrow a_2\rightarrow null$，$b_1\rightarrow b_2\rightarrow b_3\rightarrow null$。此时`p`的路径过程为$a_1\rightarrow a_2\rightarrow null\rightarrow b_1\rightarrow b_2\rightarrow b_3\rightarrow null$；`q`的路径为$b_1\rightarrow b_2\rightarrow b_3\rightarrow null \rightarrow a_1\rightarrow a_2\rightarrow null$。
```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode* p = headA;
        ListNode* q = headB;
        while (p != q) {
            p = p ? p -> next : headB;
            q = q ? q -> next : headA;
        }
        return p;
    }
};
```
