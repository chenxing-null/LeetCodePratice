[172. 阶乘后的零 - 力扣（LeetCode）](https://leetcode.cn/problems/factorial-trailing-zeroes/description/)

针对于这道题目求解的答案为 $n!$质因子分解中的 $(2,5)$的对数， $5$出现之前，一定有 $2$的出现，因此我们只需要求解其中的质因数分解中的 $5$的个数。

暴力解法：

```c++
int main()
{
    int n = 100;
    int ans = 0;
    for (int i = 1; i <= n; i++)
    {
        int j = i;
        while (j % 5 == 0 && j != 0)
        {
            ans++;
            j /= 5;
        }
    }
        std::cout << "Stand ans:" << ans << std::endl;
    return 0;
}
```

但是这个过程我们可以进行化简降至对数复杂度，要求解 $n!$中质因子 $p$的个数，可以通过下述公式求解：

$$
count_p(n)=\lfloor{{n\over p^1}\rfloor}+\lfloor{{n\over p^2}\rfloor}+\cdots +\lfloor{{n\over p^k}\rfloor}(while\quad p^k≤n)
$$
