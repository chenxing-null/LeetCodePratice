[环形链表Ⅱ](https://leetcode.cn/problems/linked-list-cycle-ii/?envType=study-plan-v2&envId=top-100-liked)

给定一个链表的头节点 `head` ，返回链表开始入环的第一个节点。 如果链表无环，则返回 `null`。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（**索引从 `0` 开始**）。如果 `pos` 是 `-1`，则在该链表中没有环。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

**不允许修改**链表。

$Solution$：

- 使用快慢指针判断单链表中是否存在环：假设不存在环，`slow`每次步长为 $1$，`fast`每次步长为 $2$，那么`fast`一定早于`slow`走到`null`。

```cpp
LinkNode* slow = head;
LinkNode* fast = head;
while (fast && fast -> next) {
    slow = slow -> next;
    fast = fast -> next -> next;
}
return false; // 没有环存在
```

- 如果存在环，那么可以将环想象成一个环形跑道，当`slow`到达入环口的时候，`slow`与`fast`之间存在着距离 $d$，但是当两者分别以步长为 $1$和 $2$进行运动的时候，两者之间的相对运动距离为 $1$，又因为跑道是环形的，当相对运动的距离 $rm+d=c$时，`slow`会与`fast`相遇。因此，有环存在就等价于某一时刻`slow == fast`。

```cpp
LinkNode* slow = head;
LinkNode* fast = head;
while (fast && fast -> next) {
    slow = slow -> next;
    fast = fast -> next -> next;
    if (slow == fast) {
        return true; // 有环存在
    }
}
return false; // 没有环存在
```

- 而现在的问题转化为了，要求我们找到入环口的节点，这个时候我们就要关注如果`slow`与`fast`相遇了，那么相遇的这一刻与入环口的关系了。

- 设从`head`节点走到入环口需要 $a$步，链表的环长为 $c$，那么当`slow`走到入环口的时候，`fast`一共走了 $2a$步，`fast`在环中的位置（也可以说是`fast`相对于`slow`多走的步数）为 $d=a\%c\rightarrow a=kc+d$，这也就意味着`slow`要再走 $c-d$步才能与`fast`相遇。（每次相对运动的距离为 $1$）。那么相遇时`slow`离入环口的距离即为 $c-d$，`slow`以步长 $1$走到入环口需要的距离即为 $c-(c-d)=d$，如果我们从相遇的时刻起，让`head`也以步长 $1$向前走，那么两者一定会在入环口相遇。


- 证明：当`slow`自相遇起走了 $d$步到达入环口的时候，`head`距离入环口的距离为 $a-d=kc+d-d=kc$，此时两者都以 $1$为步长，在 $kc$步之后一定在入环口相遇。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast -> next) {
            slow = slow -> next;
            fast = fast -> next -> next;
            if (slow == fast) {
                ListNode* ptr = head;
                while (ptr != slow) {
                    slow = slow -> next;
                    ptr = ptr -> next;
                }
                return slow;
            }
        }
        return NULL;
    }
};
```
